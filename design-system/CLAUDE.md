# Luft portfolio: instructions for Claude Code

Build Suki's portfolio site with the Luft design system in this folder.

1. Read `README.md` first: principles, colour roles, type, layout, pages and build notes.
2. Use `tokens.css` for every colour, font, space and radius (CSS custom properties). Never hard-code hex values. `tokens.json` is the source of truth if you need to regenerate it.
3. Each folder in `components/` has a `README.md` (the rules) and a `preview.html` (a reference rendering that uses the token variables). Build real components from them; `Cover` is only artwork.
4. Radio Luft images are in `assets/radio-luft/`.
5. The interactive reference for every page, including the phone layout, is the Luft Portfolio design canvas: https://claude.ai/artifact/MPth3z4whA4Ui8FEaZ8aN2
6. The online copy of this system: https://claude.ai/artifact/1aS9svPGHNzNKvK5MdSnrZ
