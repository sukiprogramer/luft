# Footer

The same dark footer closes every page: a big "Say hi." sign-off, page links, contacts and the wordmark.

- Ground `night`, text `on-night`; labels "PAGES" and "ELSEWHERE" in 11px tracked caps, `on-photo`.
- Sign-off: `display-xl` Fraunces, "hi." in `yellow`, with an accent **Get in touch** button that opens the SayHiDialog.
- Bottom row: the LUFT wordmark (28px) and "Made with paper, ink and a lot of music. © [Year] Suki", above a 1px rule.
- Phones: the sign-off drops to 64px, the button goes full width, links sit in one row.
