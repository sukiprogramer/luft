# PosterCard

A yellow block that works like a gig poster: a big display headline, one doodle, a line of text and one button.

- Ground `yellow`, text and doodle `on-yellow`, 2px `on-yellow` border, `radius-0`, padding `space-7`.
- Headline: `display-m` to `display-l` Fraunces with SOFT and WONK on, two short lines.
- One doodle (squiggle or sticker) in the top-right corner. Never more than one.
- Button: primary style (dark ground, yellow text).
- Use at most one poster card per screen. A violet version (`violet` ground, `white` headline, `on-violet` text) is used for Radio Luft and Trackmate.
