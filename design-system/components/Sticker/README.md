# Sticker

A 14-point starburst, like a price sticker on a poster, plus the hand-drawn squiggle used beside it.

- Starburst: outer radius 60, inner 46 in a 128 viewBox; fill `yellow`, 2.5px `ink` stroke, round joins.
- Label: one or two words, Poppins 600 13px uppercase in `on-yellow`, centred on two lines.
- Placement: overlapping the top-right corner of a photo or card, partly off its edge.
- Squiggle: an inline SVG path, 2.5–3px `ink` stroke with round caps. Decorative, so `aria-hidden="true"`.
- One sticker per screen. Never rotate the text.
